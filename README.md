# Proyecto Unity

## Requisitos
- Unity Hub.
- Unity Editor (versión indicada en `ProjectSettings/ProjectVersion.txt`).

## Instalación y ejecución
1. Descargar o clonar el proyecto.
2. Abrir Unity Hub y seleccionar **Add > Add project from disk**.
3. Seleccionar la carpeta del proyecto.
4. Esperar a que Unity importe los recursos.
5. Abrir la escena principal y presionar **Play**.
